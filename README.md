# Deepfake Image Detection — Kaggle Project

## Project Goal

> Investigate how well an image deepfake detector can generalize to fake images generated by methods it has not seen during training.

Main environment: **Kaggle Notebook**

Main framework: **Python + PyTorch**

Initial model: **Pretrained ResNet**
